# Pastas Caseras Martita · Catálogo mayorista

Página de catálogo y pedidos mayoristas. Es un único archivo (`index.html`), sin dependencias locales.

## Antes de publicar
- Reemplazar `NUMERO_WHATSAPP` (en el bloque `<script>`) por el número real, con código de país (ej.: 54 9 381 ...).
- Cargar precios reales en `PRODUCTOS`.
- Confirmar presentaciones de tartas y de la caja.

## Publicar
Subir `index.html` a un repositorio y activar GitHub Pages (o usar Netlify / Cloudflare Pages). Luego conectar el dominio desde el panel del hosting.
